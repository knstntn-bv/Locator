ID событий — постоянные UUIDv5 из ключей каталога. ON CONFLICT (id) DO NOTHING позволяет повторить загрузку без дубликатов и без перезаписи существующих строк с этими ID. Существующие строки с другими ID не удаляются и не сопоставляются по названию. Генератор: `python data/build_moscow_migration.py`; он использует текущие координаты JSON без сетевых запросов. Исходный JSON сохраняет прежние поля; преобразование в колонки новой схемы выполняется при генерации SQL.
