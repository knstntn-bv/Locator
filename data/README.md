# Находки Москвы: 23.11.2026–15.01.2027

`moscow-events.json`: 81 запись из доступной исходной беседы. `moscow-conversation-source.json` сохраняет полный ответ read_thread с исходными сообщениями и календарными ссылками. API сообщил hasMore=false; полнота ограничена предоставленной историей.

Даты, цены и площадки — утверждения исходной беседы, а не независимо проверенные факты. Все записи unverified. Для строк без прямой ссылки сохранены общие источники соответствующего сообщения; они не являются подтверждением конкретного события. Январь трактуется как 2027 год. Серия «Японский маджонг и го» заменена шестью встречами по средам: 25.11, 02.12, 09.12, 16.12, 23.12 и 30.12.2026. Даты рассчитаны по указанию пользователя и хранятся в date; исходное расписание сохранено в reported_date, связь серии — в series_key. Сеансы не подтверждены организатором; время не задано. Серия «День открытых дверей Клуба волонтёров» удалена из каталога по указанию пользователя; исходный снимок беседы сохранён без изменений. Десять событий вне периода исключены (РусАртСтиль, Fairy Fair, Ceramania, Уникальная Россия, Тогучи, МАСТЕРскаЯ, ALIA FEST, ЛУК, VIBE.CON, Magic Fest).

Схема public.events требует starts_at, ends_at, location_name, latitude, longitude. Достоверных полных наборов пока нет. Находки сохранены только в JSON; новые таблицы и миграции не создаются. Для вставки в events необходимо сначала проверить время, адреса и координаты.

Проверка проведения событий не выполнялась.

Ответы API: `moscow-geocoding-results.json`; сводка и нерешённые запросы: `moscow-geocoding-summary.json`; повторяемая обработка: `geocode_moscow.py`.
