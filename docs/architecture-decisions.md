# Eventr — архитектурные решения

## Раздельные даты и время событий POC

По решению пользователя даты начала и окончания обязательны, а время начала и окончания необязательно. Реализованы поля `start_date`, `end_date`, `start_time`, `end_time`. Времена могут отсутствовать независимо; `timezone` сохраняется. Отсутствующее время означает неизвестное время, а не полночь.

Фильтр POC сравнивает календарные даты событий включительно без преобразования в UTC и без учёта необязательного времени. В попапе показываются только заданные времена. Для одного дня при двух заданных временах окончание должно быть позже начала. Это уточнение заменяет прежнюю модель обязательных UTC-меток начала и окончания для POC.

Переход существующей БД: `003_split_event_dates.sql`. Создание с нуля: `supabase/schema.sql`, тестовые данные: `supabase/seed.sql`. Исторические миграции сохранены без изменений.

## Текущий этап: proof of concept

Для первой проверки пользователь сузил объём: только карта с зумом, попапы событий и фильтр по начальной и конечной датам. В БД только события; одноразовое заполнение SQL-миграцией. Пользователи, роли приложения и остальные функции полной спецификации в POC не входят.

Реализация: Vite + TypeScript без UI-фреймворка, MapLibre + OpenFreeMap, публичное чтение таблицы событий Supabase. PostGIS, серверные функции и очереди для этого этапа не требуются. Это упрощение реализации POC, а не отмена продуктовой спецификации MVP.

Инструкции подключения и ограничения: [README](../README.md).

## ADR-001. Карта нулевой версии: MapLibre + OpenFreeMap

- Дата: 23 ноября 2026 года.
- Статус: принято пользователем в текущем обсуждении.
- Область: нулевая версия Eventr.

### Контекст

Нулевую версию пользователь решил размещать на GitHub Pages. Нужна глобальная карта, допускается основа OpenStreetMap. Карта должна отображать события Eventr и поддерживать дальнейшую реализацию маркеров, кластеризации и поиска событий в видимой области.

### Решение

Использовать **MapLibre GL JS** для отображения карты в браузере и **публичный сервис OpenFreeMap** как поставщика векторных тайлов и готового стиля карты.

Распределение ответственности:

| Компонент | Ответственность |
| --- | --- |
| GitHub Pages | Хостинг статического интерфейса нулевой версии |
| MapLibre GL JS | Отображение карты и слоя событий в браузере |
| OpenFreeMap | Подложка карты на основе OpenStreetMap со схемой OpenMapTiles |
| Данные Eventr | Отдельный слой событий; не передаются поставщику тайлов для хранения |

Ранее предложенная схема предусматривает получение событий из Supabase. Этот ADR фиксирует выбор картографической связки и не утверждает автоматически остальные предложенные компоненты стека.

### Причины выбора

- Совместимость с размещением интерфейса на GitHub Pages.
- Возможность начать без подключения биллинга карт.
- Для публичного сервиса OpenFreeMap не нужны регистрация и API-ключ.
- Возможность позднее заменить поставщика совместимых тайлов и стиля, сохранив MapLibre и модель событий.

### Условия и последствия

По информации OpenFreeMap, проверенной 23 ноября 2026 года:

- Публичный сервис бесплатен; для обычного отображения карты заявлено отсутствие лимитов на просмотры и запросы.
- Коммерческое использование разрешено.
- Гарантии доступности (SLA) и персональная поддержка не предоставляются.
- Требуется сохранять атрибуцию источников карты. При интеграции необходимо проверить её видимость, включая мобильный интерфейс.

Это условия внешнего сервиса на дату проверки, а не гарантия их неизменности. Ограничения офлайн-загрузки рассматриваются отдельно; решение не предусматривает офлайн-карты.

OpenFreeMap предоставляет картографическую подложку. Поиск адресов, подсказки мест и преобразование адресов в координаты требуют отдельного решения.

### Открытые вопросы

- Конкретный стиль подложки и язык подписей.
- Поставщик поиска адресов и геокодирования, если они потребуются в нулевой версии.
- Вид маркеров, поведение кластеров и обработка совпадающих координат.
- Нужен ли резервный поставщик карты при недоступности OpenFreeMap.

Ни один из этих пунктов не считается утверждённым данным решением.

### Рассмотренные альтернативы

Google Maps, MapTiler, Geoapify, Mapbox, HERE и TomTom обсуждались как альтернативы. Для нулевой версии выбран OpenFreeMap с MapLibre; перечисленные сервисы не выбраны.
